# Ravensbrew Coffee Roastery
A fully responsive 4-page website for a small-batch coffee roastery, built as a final project to demonstrate HTML5, CSS3, SCSS, and Bootstrap.
## Description
Ravensbrew is a fictional direct-trade coffee roastery. The site includes a homepage with a hero section, roast-profile breakdown, product highlights, benefits, and testimonials; an About page with company story, timeline, values, and team; a Products page with a filterable product grid and FAQ accordion; and a Contact page with contact details, a map embed, and a contact form.
## Technologies Used
- HTML5 (semantic structure)
- CSS3
- SCSS (variables, nesting, mixins, `@include`, partials)
- Bootstrap 5 (grid system, navbar, cards, accordion, forms)
- Custom media queries for additional responsive behavior
- Git & GitHub for version control
